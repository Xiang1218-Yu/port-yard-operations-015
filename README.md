# HarborGrid · 港口集装箱堆场作业协同与闸口调度系统

React + Vite + TypeScript 前端，Node.js + Express + TypeScript 服务端。面向中型集装箱码头，把船期、箱务、堆场区块、闸口预约、设备作业和异常闭环放在同一套作业控制台中。

## 启动

```bash
npm install
npm run dev
```

前端默认 Vite 端口 5178，API 默认 `http://localhost:4107`。

## 业务能力

- 船舶航次、泊位窗口、计划/已完成翻箱和延误风险
- 箱号、尺寸、冷藏温度、危险品级别、海关状态、进出口/中转流向
- 堆场区块容量、堆存热度、冷藏插座、危险品隔离和设备可达性
- 闸口预约时隙、车道、OCR/称重/封志校验状态与同车冲突检测
- 岸桥、场桥、集卡、正面吊设备池和约束感知任务队列
- 自动堆位推荐、冷藏/危险品约束、海关查验阻塞、任务指派审计
- React 控制台支持船期驾驶舱、闸口操作、堆场热区与设备任务操作

## 实时推送

`GET /api/events` 提供 SSE 事件流，航次、箱务、堆场、闸口、任务、设备、告警和驾驶舱指标按统一事件格式（单调游标 id + 模块 + 类型 + 负载）推送：

- **按模块订阅**：`?modules=containers,tasks` 服务端过滤，前端 `RealtimeClient.subscribe(module, handler)` 按模块分发，单个订阅异常被隔离
- **断线重连**：指数退避重连并携带最后事件游标（`lastEventId`），服务端从环形缓冲回放错过的事件；游标过期则下发 `resync` 全量重建
- **快照与增量**：新连接先收 `snapshot`（含游标）再收有序增量，与快照重叠的增量按游标去重
- **空闲清理**：15s 心跳保活，服务端周期清理写入停滞、积压过多和超龄连接；客户端 45s 无消息判定僵死主动重连
- **编辑冲突保护**：实时更新命中正在编辑的记录时保留用户输入，提示"基线已变化"，可手动选择以最新值重填，不会无声覆盖

当前使用内存种子数据，领域服务通过 REST API 暴露，设备/船期/堆场由遥测模拟器持续产生事件，后续可接入 TOS、OCR、称重、RTG 遥测、预约配额和优化求解器。
